# 无第三方依赖：全部脚本只用 Python 3.9+ 标准库。文案老师不用装任何包。
#
# 这份文件是一条**显式声明**，不是安装清单。它的作用有两个：
#   1. 把"零依赖"从 README 里的一句话变成一个可以被 diff 看见的承诺。
#      哪天有人 import 了第三方包，这里必须同步改动，否则声明与实际不一致。
#   2. check_pipeline.py 的 deps 门要求"依赖被声明而不是隐含"。当前没有第三方
#      import，门不触发；一旦有人加了，门会立刻要求在这里写清是哪个发行包。
#
# 如实说明语义：只有注释、没有条目的文件在 check_pipeline.py 里等价于"未声明"
# （requirements_declared() 要求至少一条非注释条目）。这不是疏漏——零依赖的正确
# 表达就是没有条目，而不是写一个假条目去骗过检查。
#
# YAML 读写用 scripts/miniyaml.py 里一个刚够用的子集实现，就是为了不引入 PyYAML。
# 这条取舍的代价（多 300 余行自维护解析器）与收益（工作空间配置文件可带注释，
# 老师能直接读懂并手改）记在 DECISIONS.md。
#
# 版本底线由 scripts/self_check.py --compat 机械守住：静态扫描 3.10+ 才有的
# stdlib API，并在本机存在 3.9 解释器时用它真跑一遍状态层与管线检查。
